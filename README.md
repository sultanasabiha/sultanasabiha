## 🔭 Research

**XOAI — Explainability Evaluation & OOD Detection Toolkit** *(DRDO, private)*  
Modular Python framework evaluating post-hoc XAI methods (SHAP, LIME, Integrated 
Gradients, DEEPLIFT and so on) across vision and tabular models using faithfulness, sensitivity, 
stability & robustness metrics via Quantus, Captum, AIX360, Alibi-detect.  

**BVF Alignment — Geometric Interpretability of LLM Residual Streams** *(APPCAIR, private)*  
Residual stream analysis pipeline applying Frenet-Serret differential geometry 
to transformer activations — characterising curvature (κ) and torsion (τ) across 
layers to study how language models process safe vs harmful prompts. Combines 
component attribution, PCA trajectory analysis across base and instruct variants of Qwen2.5.
